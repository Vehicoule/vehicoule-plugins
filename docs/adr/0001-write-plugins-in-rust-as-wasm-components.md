# 0001. Write plugins in Rust, as Wasm components with no WASI

- Status: Accepted
- Date: 2026-11-07
- Deciders: the user

## Context

This ADR records, for this repository, decisions the user took for Vehicoule on 2026-11-06; it decides nothing new.

- Vehicoule is written in Rust only, with no JavaScript engine (Vehicoule's
  [ADR 0001](https://github.com/Vehicoule/Vehicoule/blob/main/docs/adr/0001-rust-only.md)).
- Plugins are Wasm components run by Wasmtime with the component model; they import only the contract's own
  interfaces, never WASI, and build for `wasm32-unknown-unknown` before being turned into components (Vehicoule's
  [ADR 0007](https://github.com/Vehicoule/Vehicoule/blob/main/docs/adr/0007-plugin-host.md), "What a plugin may
  import", option 1). Crates that need randomness or the file system do not work there, "which is the point".
- The plugin host's own test plugins are written this way: Rust, `wit-bindgen` 0.63.0, built for
  `wasm32-unknown-unknown`, turned into components with `wasm-tools component new` (Vehicoule,
  `scripts/build-plugin-fixtures.sh` at `4f61277`).

## Options

1. **Rust, `wasm32-unknown-unknown`, `wit-bindgen`, no WASI.** What the host accepts and what its test plugins do.
2. **Another language that compiles to components.** Excluded by Vehicoule's ADR 0001.
3. **`wasm32-wasip2`.** Excluded by Vehicoule's ADR 0007: the host refuses a component that imports WASI.

## Decision

Option 1. Every plugin is a Rust crate built for `wasm32-unknown-unknown` and turned into a component with
`wasm-tools`, its bindings generated by `wit-bindgen` from the pinned copy of the contract
([ADR 0002](0002-pin-the-contract-and-check-plugins-in-the-real-host.md)).

## Consequences

- `rust-toolchain.toml` pins the toolchain of Vehicoule's host, with the `wasm32-unknown-unknown` target.
- A dependency must build for `wasm32-unknown-unknown` without WASI; CI's Clippy run for that target shows it.
- The tests run natively, where the host's imports do not exist; the plugin's code is written so its tests need none
  of them ([`docs/plugin-crates.md`](../plugin-crates.md), section 2).
